Society Management Project - Demo Guide

One-page demo summary for client/interviewer sharing

Project Summary

  • Role-based platform for Admin, Society Admin, Wing Admin, Guard, and Resident.
  • Core modules: Visitor management, complaints, billing, notices, events, attendance, and reports.
  • Secure login with JWT-based authorization and protected routes.
  • WhatsApp and email notification integrations for operational workflows.

Key Demo Flows

  • Resident raises visitor request -> Guard verifies entry/exit with QR.
  • Resident submits complaint -> Society/Admin tracks and updates status.
  • Admin views reports, audits, and role configuration.
  • Demo visitor form submission triggers WhatsApp and email alerts.

Tech Stack

  • Frontend: React + Vite + Ant Design
  • Backend: Node.js + Express
  • Database: MongoDB + Mongoose
  • Realtime: Socket.IO
  • Integrations: WhatsApp Cloud/Web, Nodemailer

Suggested Live Demo Sequence (5-7 minutes)

1) Login as Admin -> show dashboard and reports.
2) Open Demo Visitors page -> show new demo request entries and status updates.
3) Login as Resident -> create visitor request and complaint.
4) Login as Guard -> approve gate flow, mark arrival/exit, QR verification.
5) Return to Admin/Society role -> show resolved workflow and activity visibility.
